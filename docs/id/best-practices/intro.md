# Praktik Terbaik {#best-practices}

Nix adalah alat yang andal dan luwes, dengan beragam cara untuk menyelesaikan tugas.
Terkadang, ini membuat kita sulit menentukan cara yang paling cocok untuk pekerjaan
tertentu. Untuk membantu menjelajahi ekosistem yang luas ini, saya mengumpulkan beberapa
praktik terbaik yang saya pelajari dari komunitas. Semoga praktik-praktik ini bermanfaat
untukmu.

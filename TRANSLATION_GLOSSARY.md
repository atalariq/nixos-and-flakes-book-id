# Glosarium terjemahan komunitas Indonesia

Karya sumber: **NixOS & Flakes Book**, Ryan Yin. Terjemahan komunitas ini bukan karya asli
atau versi resmi. Karya sumber dan adaptasi ini berlisensi
[CC BY-SA 4.0](http://creativecommons.org/licenses/by-sa/4.0/?ref=chooser-v1).

| Istilah sumber                | Keputusan terjemahan                                                      |
| ----------------------------- | ------------------------------------------------------------------------- |
| Nix, NixOS, Flakes, Nixpkgs   | Pertahankan nama resmi dan kapitalisasi sumber.                           |
| derivation                    | Pertahankan `derivation`; jangan disamakan dengan paket atau hasil build. |
| attribute set                 | Pertahankan `attribute set`.                                              |
| attribute                     | atribut                                                                   |
| Home Manager, devShell        | Pertahankan nama resmi.                                                   |
| declarative configuration     | konfigurasi deklaratif                                                    |
| reproducibility               | reproduksibilitas                                                         |
| reproducible                  | dapat direproduksi; secara reproduktif bila menerangkan cara              |
| composability                 | kemampuan komposisi; kemampuan menggabungkan sesuai konteks               |
| dependency                    | dependensi                                                                |
| package / package manager     | paket / pengelola paket                                                   |
| module / submodule            | modul / submodul                                                          |
| input / output                | input / output; jangan mengubah identifier                                |
| file / directory              | berkas / direktori                                                        |
| path                          | path; jangan mengubah nilai path                                          |
| default                       | bawaan                                                                    |
| rollback                      | rollback; kembali ke keadaan sebelumnya sesuai konteks                    |
| generation                    | generasi                                                                  |
| build                         | build; membangun untuk verba bila cocok                                   |
| deployment / deploy           | deployment / menerapkan sesuai konteks                                    |
| binary cache                  | cache biner                                                               |
| shell, host, boot, bootloader | Pertahankan istilah teknis.                                               |
| overlay / overriding          | Pertahankan overlay / overriding; menimpa untuk verba override.           |
| debugging                     | debugging                                                                 |
| breaking change               | perubahan yang merusak kompatibilitas                                     |
| lazy evaluation               | evaluasi malas                                                            |
| source tree                   | pohon sumber                                                              |
| you / we / I                  | kamu / kita / saya; pertahankan sudut pandang sumber.                     |

Judul rujukan eksternal, pesan kesalahan literal, nama produk, identifier, URL, dan semua
isi code fence (termasuk komentar) dipertahankan. Teks kutipan yang diterjemahkan tetap
berstatus kutipan. Jangan memperbarui klaim historis sumber atau menambahkan penjelasan
teknis yang tidak ada pada sumber.
